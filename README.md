## How to Run
1. Clone or download this repository:
   ```bash
   git clone https://github.com/vkcs234/Varun_Portfolio.git
   ```
2. Open the folder in your code editor (e.g., VS Code).  
3. Open `index.html` in any web browser to view the portfolio.
